Issues We Fixed (15)

Grouped by presenter, in the order each person covers them.

Issue OWASP Category Security Risk What We Added How It Ensures the Fix Member
SQL Injection in job search A03:2021 – Injection User input parsed as a DB query-language expression — broke queries, leaked internal errors Swapped to_tsquery for plainto_tsquery in GetAllPosts Input is always treated as plain search text, never as query syntax Anuka
Next.js RCE advisories A06:2021 – Vulnerable & Outdated Components Known unauthenticated remote-code-execution vulnerabilities in the framework version Upgraded Next.js 15.5.9 → 15.5.26 Patched release closes the published advisories; verified via npm audit + build Anuka
No file-type validation on uploads A03:2021 – Injection An SVG with an embedded <script> could upload as a "logo" — stored XSS if opened directly ValidateUploadContentType — sniffs real bytes via http.DetectContentType File is checked against an allow-list by its real content, not the client-sent header Anuka
SSRF via unrestricted résumé download A10:2021 – Server-Side Request Forgery Engine fetched any URL handed to it — a compromised queue message could reach internal services or cloud metadata endpoints Host allow-list (res.cloudinary.com, HTTPS only) in download_file() URL is checked against the allow-list via urlparse().hostname before any request is made Anuka
Broken access control on update/delete A01:2021 – Broken Access Control Any logged-in user could edit or delete another user's company, post, or application Ownership check before every update/delete/create-post action Action only proceeds if the caller actually owns the resource, else 403 Sashiru
Missing anti-clickjacking header A05:2021 – Security Misconfiguration Site could be framed in a hidden iframe to trick users into unintended clicks X-Frame-Options: DENY + CSP frame-ancestors 'none' Browser refuses to render the page inside any frame, on any site Sashiru
No Content Security Policy A05:2021 – Security Misconfiguration No restriction on what scripts/resources a page can load if content is ever injected Nonce + 'strict-dynamic' CSP via Next.js middleware Only the app's own nonced scripts run; verified live with zero console violations Sashiru
Other security headers missing A05:2021 – Security Misconfiguration MIME-sniffing, no forced HTTPS, referrer leakage, unneeded browser feature access X-Content-Type-Options, HSTS, Referrer-Policy, Permissions-Policy Safe, restrictive defaults now applied to every single API response Sashiru
No CSRF protection A01:2021 – Broken Access Control A malicious page could trigger create/update/delete actions using a victim's own session cookie CSRFProtection middleware — validates the request's Origin Rejected unless Origin matches our real frontend; browsers can't forge this header Dinuka
Password hash exposed to frontend A02:2021 – Cryptographic Failures bcrypt hash returned in API responses and persisted into browser localStorage json:"-" tag on the Password field Hash is never serialized into any API response, by design — not per-endpoint Dinuka
JWT signature errors ignored A07:2021 – Identification & Authentication Failures A token with an invalid/forged signature still had its claims trusted — full auth bypass Abort with 401 unless err == nil and token.Valid Any unverified or tampered token is rejected before its claims are ever read Dinuka
No rate limiting on the API A07:2021 – Identification & Authentication Failures Brute-force login attempts and volume-based abuse possible on any endpoint Redis-backed limiter — global cap, plus a stricter cap on login/signup Excess requests per IP get 429, rejected before reaching the handler Manushi
JWT exp claim could crash server A07:2021 – Identification & Authentication Failures A missing/non-numeric exp claim panicked the request instead of failing safely Comma-ok type assertion on the claim A malformed claim is now just treated as invalid — never a crash Manushi
No server-side role validation A04:2021 – Insecure Design Client could set its own signup type (account role) to anything, unchecked Allow-list check on type at signup Only the two real self-service roles can ever be assigned Manushi
Unpinned dependencies (Matchup Engine) A08:2021 – Software & Data Integrity Failures A fresh build could silently pull a newer, unreviewed, possibly vulnerable release Pinned all 11 direct dependencies to already-tested versions Every build installs the exact same, already-verified versions Manushi
